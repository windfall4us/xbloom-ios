## 在 App 里会看到什么

- 服务端**没设口令**时：与之前完全一样，不需要任何操作
- 服务端**设了口令**后：读页面照常（豆仓、萃取、调整、同步都能看），第一次做写操作（保存豆、记录反馈、设为当前版本、AI 生成、推云端）会弹一次口令面板
- 输错一次会再问一次并提示「口令不正确，再试一次」；正确后令牌存本地，之后不再问

## 新增的 4 条校验

1. 令牌头常量 `X-XBloom-Token` 在包内
2. 令牌存 `localStorage`（key `xbloom_auth_token`）
3. 401 只重试两次（`attempt<2`）
4. 鉴权路径里没有 `alert(`（会阻塞 WKWebView）
