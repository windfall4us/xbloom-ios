# v0.2.1 — 不写死内网地址；首次启动引导配置

v0.2.0 的包复核（F-03）指出：源码与文档里写死了内网地址 `192.168.50.22:8088`，而这个仓库是 **public**。
v0.2.1 只改这一件事。

## 改动

| 项 | v0.2.0 | v0.2.1 |
|---|---|---|
| `xbReadServer()` 默认值 | `'http://192.168.50.22:8088'` | `''`（空串） |
| 未配置时的 `absURL()` | 拼出内网地址 | 直接返回原路径，不拼主机 |
| 首次启动 | 静默用内网地址（在别人那里必然失败） | 自动弹出服务器面板 + 提示「首次使用请填写 xBloom 服务器地址（形如 http://主机:8088）」 |
| 包内 `192.168.50.` 出现次数 | 1 | **0** |

其余（基线 `2721ce75`、7 个 iOS 补丁、`ALIGN` 字号对齐、7 个 token）与 v0.2.0 完全一致。

## 首次使用流程

1. 安装后打开 → 面板自动弹出，输入框为空
2. 填入你的服务器地址（如 `http://你的主机:8088`）→ 保存 → 页面刷新并加载豆仓
3. 之后随时可以点右下角「🛜 服务器」改地址
